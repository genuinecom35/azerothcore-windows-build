# AtlasMall — расширенный магазин AtlasLoot Enhanced на GM Island (Legion 7.3.5)

Этот модуль создаёт **постоянных вендоров с предметами из таблиц AtlasLoot Enhanced 8.07.13**, отдельно от сервера WoW 3.3.5a.

## Телепортация

В чате GM-персонажа используйте **.mall**. Дополнительная встроенная команда — **.tele AtlasMall**. Также добавляется точка **.tele GMIsland**, если имя GMIsland не занято уже существующей точкой. Обе команды доступны GM с уровнем **SEC_MODERATOR** и выше.

Точка входа — остров GM (Kalimdor, карта 1), примерно X=16222.22, Y=16252.62, Z=12.62. Продавцы расставляются компактными рядами рядом с телепортом. **Точные позиции и высоты необходимо проверить в игре:** карты Legion в автоматическом сборочном контейнере отсутствуют.

## Какие товары

Таблицы предметов считываются из модулей AtlasLoot Enhanced версии 8.07.13, рассчитанной на клиент 7.3.5:
- Classic / The Burning Crusade / Wrath of the Lich King;
- Cataclysm / Mists of Pandaria / Warlords of Draenor;
- Legion;
- Коллекции / фракции / PvP / профессии / события.

Добыча рейдов и подземелий распределяется по отдельным категориям и страницам. Для каждой страницы создаётся NPC с максимумом **115 товаров** (ограничение LegionCore — 150). Каждый товар представляет базовый **item ID** AtlasLoot, без дополнений или изменения уровня предметов, которые в оригинальном аддоне задаются бонусами и сложностью. Цены берутся из базы сервера; ExtendedCost=0.

**Не гарантируется**, что каждый ID из каталога присутствует в загруженных клиентских данных и не ограничен классом, уровнем или уникальностью. Фактический ассортимент и выдачу предметов следует проверить внутри игры.

## Установка

В новой сборке Legion SQL-файл находится по пути:
`sql/updates/world/2026_10_28_90_atlasmall.sql`.

При **первом запуске** `worldserver.exe` применит его через встроенный SQL-апдейтер. Для уже работающей базы Legion нужно перезапустить `worldserver`, чтобы обновление загрузилось. **Не импортируйте** этот SQL в базу WoW 3.3.5a — структура не совместима.

Команда `.mall` добавлена в `cs_tele.cpp` при компиляции; её нельзя включить только SQL-файлом. Нужны именно свежие бинарные файлы из новой сборки.

В архив дополнительно входят `ATLASMALL_MANIFEST.json` (количество вендоров и позиций) и эта инструкция. Модуль генерируется по зафиксированной ревизии источника, а изменения исходного LegionCore применяются **только в рабочей папке сборки**.

## Безопасность и повторное применение

- Удаляются/переустанавливаются только специальные NPC entry **997100–997999**, GUID **99610000–99610899** и точки телепорта 997099/997100.
- Штатные NPC, предметы и квесты не заменяются.
- Повторное применение SQL рассчитано на обновление только собственного диапазона ID. Не используйте эти ID для своих NPC.
- Имеющаяся база Legion и база WoW 3.3.5a не смешиваются.

## Источник и лицензия

Исходный каталог: [AtlasLoot Enhanced — сборник модулей для Legion 7.3.5](https://github.com/pernamiau1/wow-legion-7.3.5-addons). Ревизия: `1003e6078fc6d14508df9e8548bd5ecc51409a3c`. Версия AtlasLoot Enhanced: `v8.07.13`, исходный аддон под GPL v2. Сценарий извлекает из Lua только числовые ID предметов; интерфейс и Lua-файлы аддона в серверный архив не включаются.

Вендоры независимы от установленного у игрока клиентского AtlasLoot; при желании можно поставить аддон отдельно в `Interface/AddOns`.
