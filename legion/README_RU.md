# WoW Legion 7.3.5 — Windows x64

Это отдельная сборка сервера Legion для клиента **7.3.5, build 26972**. Клиент игры, карты и другие извлекаемые данные Blizzard в архив не входят.

## Важно

- Сборка не заменяет WoW 3.3.5a/AzerothCore.
- Для Legion используются отдельные базы: legion735_auth, legion735_characters, legion735_world, legion735_hotfixes.
- Скрипт настройки не импортирует данные в базы auth/characters/world/hotfixes от WotLK и не меняет файлы прежней сборки.
- Если базы с именами legion735_* уже существуют, настройщик остановится, не перезаписывая их.
- Ядро настроено на уровень 110 и базовые коэффициенты опыта x1. Это не означает, что каждая цепочка заданий и каждый рейд проверены вручную.

## Русская локализация

- Сборка использует серверную локаль Russian (DBC.Locale = 8) по умолчанию.
- В SQL-пакет включены обновления LegionCore для исправления повреждённой кодировки русских строк: 2026_10_28_00_russian_texts_encoding.sql и 2026_10_28_01_russian_texts_leftovers.sql.
- При первом запуске worldserver.exe эти обновления применяются автоматически вместе с остальными SQL-обновлениями.
- Сервер покажет русские названия, задания, диалоги и сообщения там, где для них есть строки ruRU или другие русские локализованные данные. При отсутствии перевода клиент или сервер может использовать английский текст; это не гарантирует 100% перевода всех цепочек, скриптов и системных сообщений.
- Для русских игровых текстов нужен клиент build 26972 с файлами локализации ruRU. В клиенте выбери русский язык; если файл WTF/Config.wtf содержит параметры локали, проверь SET textLocale "ruRU" и при необходимости SET audioLocale "ruRU". Не удаляй папку Data/ruRU.
- Архив сервера не содержит клиент, клиентские языковые файлы или извлекаемые карты.

## Порядок установки

1. Распакуйте весь архив в отдельную папку, например C:\WoW-Legion-7.3.5. Не распаковывайте поверх WotLK-сервера.
2. Установите/запустите MySQL Server 8.0 или совместимый MySQL 8.4. Скрипт использует уже установленный сервер БД и не устанавливает новый.
3. Запустите SETUP_DATABASE.cmd. Укажите путь к mysql.exe, если он не найден автоматически, затем host, port и учётные данные администратора MySQL. Скрипт создаст четыре новые базы, импортирует базовые SQL и сгенерирует конфиги с отдельным случайным пользователем MySQL.
4. Возьмите свой клиент Legion 7.3.5 build 26972. Рекомендуется сначала сделать копию клиентской папки.
5. Запустите EXTRACT_CLIENT_DATA.cmd, укажите корневую папку клиента (где лежит Wow.exe) и дождитесь завершения всех этапов. Генерация mmaps может занять много времени и места. В серверную папку ClientData должны попасть dbc, maps, vmaps, mmaps, cameras и gt.
6. Запустите START_SERVER.cmd. Сначала откроется worldserver; при первом запуске он применит SQL-обновления из sql/updates. Дождитесь завершения обновления базы и готовности worldserver, затем вернитесь в первое окно и нажмите клавишу — откроется bnetserver.
7. Оставьте оба окна открытыми. Для подключения клиент должен быть настроен на ваш сервер; инструмент connection_patcher.exe включён в сборку. Перед любым патчингом сделайте резервную копию Wow.exe и используйте только клиент build 26972. Для русских текстов нужен клиент с ruRU-файлами; серверная настройка DBC.Locale = 8 выставляется автоматически.

## Если сервер не стартует

- Проверьте логи в окнах worldserver и bnetserver.
- Проверьте, что MySQL работает, а в bnetserver.conf и worldserver.conf сохранены корректные параметры подключения.
- Убедитесь, что SourceDirectory = ".", папка sql/updates находится рядом с конфигами, а все папки ClientData созданы экстракторами из build 26972.
- Не копируйте ClientData от WotLK: данные карт разных версий несовместимы.
- Не удаляйте и не заменяйте базы текущего WotLK-сервера для устранения ошибок Legion.

## Состав архива

- bnetserver.exe, worldserver.exe и инструменты извлечения;
- необходимые runtime DLL;
- bnetserver.conf.dist и worldserver.conf.dist;
- базовые SQL и SQL-обновления Legion;
- скрипты установки БД, извлечения данных и запуска;
- BUILD_INFO.txt с ревизией исходников.

Ядро основано на открытом проекте [LegionCore - Reforged](https://github.com/Titans-Project/LegionCore-Reforged). Серверные файлы не содержат клиент игры.
