AZEROTHCORE 3.3.5a — ГОТОВАЯ СБОРКА ДЛЯ WINDOWS x64
================================================================

В архиве находятся компилированные ядро AzerothCore, два модуля,
SQL-файлы базы, инструменты извлечения игровых карт, русские названия
трёх кастомных предметов и мастер первоначальной настройки.

Что необходимо на вашем Windows 10/11 (x64):
- MySQL Server 8.4 LTS, запущенный локально на 127.0.0.1:3306.
  Официальный сайт: https://dev.mysql.com/downloads/mysql/
- Клиент World of Warcraft 3.3.5a (собственный экземпляр, желательно ruRU).
- Место на диске для Data (несколько гигабайт).
- Подключение к интернету не требуется во время первоначальной инициализации
  баз, если каталог SQL_SOURCE/data/sql скопирован полностью.

БЫСТРЫЙ ЗАПУСК (локальный сервер на том же ПК):
1. Распакуйте ВСЕ файлы ZIP в каталог без ограничений доступа,
   например C:\WoWServer335. НЕ запускайте прямо из ZIP.
2. Установите и запустите MySQL Server 8.4 LTS. Запомните ROOT-пароль,
   указанный при установке. MySQL должен слушать порт 3306 локально.
3. Запустите SETUP_SERVER.cmd. Введите YES, затем дважды root-пароль
   MySQL по запросу. Мастер создаёт ТОЛЬКО новые базы acore_auth,
   acore_world, acore_characters, пользователя с отдельным длинным
   паролем и конфигурации configs\*.conf.
   При обнаружении старых баз мастер прекращает работу, не стирая их.
4. Получите игровые карты из СВОЕГО клиента 3.3.5a:
   - Запустите PREPARE_EXTRACTORS.cmd, укажите папку с Wow.exe.
   - В папке клиента запустите extractor.bat и следуйте меню.
   - Перенесите полученные каталоги dbc, maps, vmaps, mmaps
     в папку Data рядом с worldserver.exe.
   - dbc и maps обязательны, vmaps и mmaps настоятельно рекомендуются.
   - Для русского клиента используйте экстракцию именно его данных.
5. Запустите DIAGNOSTICS.cmd — он проверяет наличие необходимых файлов.
6. Запустите START_SERVER.cmd, подтвердите автоматическую инициализацию
   базы в появившихся консолях, если будет вопрос, и дождитесь
   окончания первого импорта базы. Время зависит от компьютера.
   Сервер запускается на 127.0.0.1:3724 (auth) и :8085 (world).
7. После первого успешного старта остановите worldserver,
   сделайте резервную копию БД и запустите
   CUSTOM\APPLY_CUSTOM_ITEMS.cmd для импорта трёх демонстрационных
   предметов + ruRU-локализации.
8. Снова запустите START_SERVER.cmd.
9. В консоли worldserver создайте аккаунт:
       account create testuser ВАШ_ПАРОЛЬ
   Для администратора:
       account set gmlevel testuser 3 -1
   Выберите надёжные логин/пароль и не используйте их публично.
10. В клиенте WoW 3.3.5a откройте Data\ruRU\realmlist.wtf
    (или Data\enUS\realmlist.wtf) и запишите:
       set realmlist 127.0.0.1
    Запускайте клиент через Wow.exe, а не через официальный лаунчер.
11. GM-команды после входа:
       .additem 910001
       .additem 910002
       .additem 910003
       .npc add 190010
    Последняя команда ставит NPC трансмогрификации.

МОДУЛИ:
- Transmog: configs\modules\transmog.conf
- Auction House Bot: configs\modules\mod_ahbot.conf.
  Для аукционного бота нужно отдельно создать игровой аккаунт и
  персонажа, указать их ID в конфигурации и проверить SQL обновления.
  По умолчанию здесь не включена произвольная торговля за игрока.

ОБРАТИТЕ ВНИМАНИЕ:
- Это локальный сервер. BindIP=127.0.0.1; для доступа извне
  необходима отдельная безопасная настройка сети. Этот пакет
  НЕ открывает порты на маршрутизаторе и брандмауэре.
- Размещённые в configs\*.conf пароли базы данных нельзя
  публиковать в GitHub, Discord или отправлять посторонним.
- Автоматический SQL updater ядра использует папку SQL_SOURCE.
  Не удаляйте её после распаковки, если хотите обновлять базу.
- Не заменяйте/обнуляйте существующие базы при обновлении ядра:
  внутри acore_characters находятся персонажи, предметы и прогресс.
- Локализация SQL переводит только три кастомных предмета.
  Полный перевод диалогов, квестов и интерфейса не включён.
- Модели новых вещей уже имеются в клиенте 3.3.5a; клиентский
  MPQ-патч для этих трёх демонстрационных предметов не требуется.
- При отсутствии dll на вашей машине обратитесь к журналу
  запуска/пакету Visual C++ Redistributable, MySQL и OpenSSL.
- Сборка успешно компилировалась в GitHub, но первичная настройка
  на пользовательском Windows и запуск с игровыми данными
  требуют локальной проверки.
