# AzerothCore 3.3.5a — кастомная сборка Windows x64

Это репозиторий **инструкций и workflow**. Исходники ядра и модулей скачиваются в GitHub Actions, а не хранятся здесь.

## Что включено

- Ядро AzerothCore из `azerothcore/azerothcore-wotlk` (ветка `master`);
- [mod-transmog](https://github.com/azerothcore/mod-transmog) — трансмогрификация (NPC ID `190010`);
- [mod-ah-bot](https://github.com/azerothcore/mod-ah-bot) — аукционный бот (требует настройки учётной записи);
- 3 демонстрационных кастомных предмета с русской локализацией:
  - `910001` — Клинок северной бури (модель Thunderfury);
  - `910002` — Молот ледяного пламени (модель Sulfuras);
  - `910003` — Камень возвращения странника (модель Hearthstone).

## Компиляция

Вкладка [Actions](https://github.com/genuinecom35/azerothcore-windows-build/actions) → **Build AzerothCore 3.3.5a (Windows x64)**.
При успешном завершении скачайте артефакт **AzerothCore-3.3.5a-Windows-x64**.
Внутри будут бинарники, конфигурации, инструменты извлечения игровых данных и папка `CUSTOM`.

GitHub Actions собирает EXE, но НЕ устанавливает MySQL, НЕ содержит WoW-клиент и НЕ создаёт автоматически игровые карты/базы.

## Установка

1. Установите MySQL и настройте стандартные базы AzerothCore (`acore_auth`, `acore_characters`, `acore_world`). Начните с [официальной инструкции](https://www.azerothcore.org/wiki/installation).
2. Скопируйте нужные `*.conf.dist` в `*.conf`, исправьте параметры подключения к БД.
3. Модульный SQL обычно применяется при старте worldserver, если включены DB updates; проверьте журнал сервера. Для аукционного бота выберите отдельный аккаунт и персонажа в `mod_ahbot.conf` (из `mod_ahbot.conf.dist`).
4. Запустите `CUSTOM\install_custom_items.cmd` после инициализации `acore_world` либо выполните SQL вручную: `mysql --default-character-set=utf8mb4 -u root -p acore_world < custom_items_ruRU.sql`.
5. Перезапустите worldserver и выдайте примеры GM-командами `.additem 910001`, `.additem 910002`, `.additem 910003`.
6. Для трансмогрификации разместите NPC через `.npc add 190010` (GM).
7. Используйте **свой** клиент WoW 3.3.5a с локалью `ruRU`; настройте `Data\ruRU\realmlist.wtf`, затем проверьте названия предметов.

## Важное

- Русские названия новых предметов находятся в `item_template_locale`. **Полный перевод всех квестов, NPC и интерфейса** этим SQL не устанавливается.
- В предметах использованы существующие модели/эффекты, чтобы не требовался MPQ-патч клиента. Это **демонстрационные** предметы, а не сбалансированная PvP/PvE-система.
- Если IDs `910001–910003` уже заняты, измените их в SQL до запуска.
- Повторный запуск SQL не создаёт дубликаты; существующие строки `item_template` не перезаписываются, но ruRU локализация трёх демонстрационных ID обновляется.
- Перед изменениями в существующей БД создайте резервную копию.
- Указанные модули имеют собственные лицензии и настройки. Совместимость конкретного снимка исходников подтверждается **только успешной компиляцией и проверкой запуска**.
